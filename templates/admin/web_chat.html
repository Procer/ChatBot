Chat Web

Un link (y un QR) que abre el chat a pantalla completa en el celular, sin instalar nada. Responde con el mismo cerebro y los mismos Conocimientos que WhatsApp.

Abrir

Sirve para el QR de recepción, un botón de tu web, redes sociales o cualquier mensaje.

Apariencia y textos

El logo del chat es el del negocio (se carga en Configuración → Empresa).

Al tocarlos, el texto se envía como una pregunta y el bot responde con los Conocimientos cargados.

Límites (cuidan el costo de IA)

Como el link es público, cualquiera con el enlace puede escribir. Estos topes evitan gastos por abuso. 0 = sin tope.
