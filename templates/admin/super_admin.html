Google Drive (cuenta de servicio propia del cliente)

Sin configurar

Cada cliente tiene su propia cuenta de servicio (dentro de nuestro proyecto de Google Cloud). No hay pantalla de consentimiento ni vencimiento: el cliente solo comparte su carpeta de Drive con el email de esa cuenta.

Paso a paso: cómo crear la cuenta de servicio y conseguir la clave JSON
  • Entrá a console.cloud.google.com, en nuestro proyecto de Google Cloud (no uno del cliente).
  • Menú (☰) → "IAM y administración" → "Cuentas de servicio" → "Crear cuenta de servicio".
  • Nombre: algo identificable con el cliente (ej: "drive-nombre-del-cliente"). No hace falta asignar roles de proyecto → "Listo".
  • Entrá a la cuenta recién creada → pestaña "Claves" → "Agregar clave" → "Crear clave nueva" → tipo JSON → se descarga un archivo.
  • Abrí ese archivo y pegá todo su contenido en el campo de abajo.
  • Guardado esto, andá al panel de este cliente → "Biblioteca de Documentos": ahí va a aparecer el email de la cuenta de servicio para que el cliente comparta su carpeta de Drive con ese email (rol Lector), como se comparte con cualquier persona.

Mínimo 5 minutos. Por defecto 480 (8hs). Cuanto más bajo, más rápido aparecen archivos nuevos subidos a Drive, pero más llamadas a la API de Google.
