# 🛠️ Stack Tecnológico

ZSG-Bot-iA utiliza un conjunto de herramientas modernas para garantizar escalabilidad, velocidad y una experiencia de usuario superior.

## Backend (El Motor)
- **Python 3.11+:** Lenguaje base por su robustez en el ecosistema de IA.
- **FastAPI:** Framework web asíncrono de alto rendimiento para el Panel Admin y los Webhooks.
- **Uvicorn:** Servidor ASGI para ejecutar la aplicación FastAPI.
- **LangChain / LangGraph:** Frameworks para la orquestación de agentes de IA y flujos de trabajo cíclicos.
- **SQLite:** Motor de base de datos relacional ligero para configuraciones, analíticas y persistencia de estados.

## Inteligencia Artificial (El Cerebro)
- **OpenAI (GPT-4o / GPT-3.5-Turbo):** Utilizado para tareas de razonamiento complejo y extracción de datos.
- **Google Gemini (1.5 Flash):** Utilizado para optimizar costos en tareas de respuesta rápida y soporte básico.
- **ChromaDB:** Base de datos vectorial para el sistema RAG (Retrieval Augmented Generation), permitiendo que el bot consulte documentos PDF/TXT.

## Frontend (Panel Admin)
- **HTML5 / Jinja2:** Motor de plantillas para renderizado dinámico desde el servidor.
- **Tailwind CSS:** Framework de diseño para una interfaz moderna y responsiva.
- **Lucide Icons:** Set de iconos minimalistas para la interfaz.
- **JavaScript (Vanilla):** Lógica reactiva para la visualización de datos y actualizaciones en tiempo real.

## Integraciones (Comunicaciones)
- **Evolution API (Docker):** Instancia de WhatsApp profesional para el envío y recepción de mensajes/archivos.
- **pyTelegramBotAPI:** Librería para la gestión nativa del bot de Telegram.
- **Green-API (Opcional):** Alternativa para integración de WhatsApp.
